## 2026-11-11 · P0 四轮评审

| 决策                   | 选择                                                 | 理由                                                                                        | 备选/代价                                     |
| ---------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------- | --------------------------------------------- |
| `.nvmrc` 的写法        | 写**最低版本** `20.19.0`，守卫脚本按 semver 比较     | 只写 `20` 时 nvm 可能选 20.18，而 `engines` 要求 `>=20.19.0`                                | 写死 20.20.2：CI/Docker 的 20.19 会被判不合格 |
| Playwright 复用 server | 回到 `reuseExistingServer: false`                    | 复用普通 dev server 时 `webServer.env`（`DB_FILENAME=test-e2e.db`）不生效，测试会打到真实库 | 复用：本地省事但可能污染数据                  |
| 棘轮 `--update` 语义   | 只允许持平或下降；放宽需 `--allow-increase "<理由>"` | 否则 `--update` 本身成为绕过闸门的后门                                                      | 自由更新：等于没有棘轮                        |
| eslint 异常退出        | status ∉ {0,1}、输出为空、非数组 → 一律失败          | 崩溃/被信号终止时 `status=null`，旧实现会把空报告当"0 条 warning"通过                       | 只判 total：会让崩溃伪装成通过                |
| Docker deps 阶段       | 额外 COPY `.nvmrc` 与 `check-node-version.cjs`       | `npm ci` 会执行 `preinstall`，缺文件会让镜像构建直接失败                                    | 去掉 preinstall：本机漂移不再拦               |
