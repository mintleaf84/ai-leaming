# FSRS (Free Spaced Repetition Scheduler) 记忆算法详解

FSRS 是目前最先进的间隔重复记忆算法之一。本系统集成该算法，旨在为您提供科学、高效的复习规划，帮助您以最少的时间成本达成最牢固的记忆。

## 1. 核心理念：间隔重复 (Spaced Repetition)

间隔重复是一种基于“遗忘曲线”的学习技术。它通过不断拉开复习间隔，在您即将遗忘的临界点提醒您复习，从而将短期记忆转化为长期记忆。

- **稳定性 (Stability)**：代表您的记忆强度。稳定性越高，遗忘越慢，下一次复习的间隔就越长。
- **难度 (Difficulty)**：代表知识点的固有难度。难度越高，稳定性增长越慢。
- **可提取性 (Retrievability)**：代表您在某一时刻回忆起该知识点的概率。

## 2. 智能化的“零感知”评估

传统的记忆软件（如 Anki）需要用户在复习后手动点击“简单”、“良好”或“困难”。为了提升刷题体验，我们实现了一套基于行为数据的**自动评分系统**：

### 纯思考时间计算
系统会根据题目的字数（题干 + 选项）估算您的阅读时间。
`纯思考时间 = 总耗时 - (字数 / 平均阅读速度)`

### 自动判定标准
根据纯思考时间，系统自动将您的表现映射为 FSRS 的评分：
- **简单 (Easy)**：纯思考时间 < 2秒。代表您对该知识点已经形成了肌肉记忆。
- **良好 (Good)**：纯思考时间在 2-8秒 之间。代表您掌握得不错，但仍需轻微思考。
- **困难 (Hard)**：纯思考时间 > 8秒。代表您虽然答对了，但过程较为吃力。
- **重学 (Again)**：只要答错，系统即判定为“重学”，重新开始记忆循环。

### 题型灵敏度修正
不同的题型决策成本不同，系统会自动进行系数修正：
- **判断题**：决策极快，系统会提高灵敏度。
- **多选题**：决策成本高，系统会给予更多的宽容度。
- **填空题**：需要打字输入，系统会扣除打字时间并使用专用阈值（简单 < 4秒，良好 4-12秒）。

## 3. 全站数据驱动的冷启动

当您遇到一道从未做过的题目时，系统不会简单地将其设为默认难度，而是会参考**全站用户的正确率**。
- 如果这是一道全站正确率极低的“神坑题”，系统会自动为您预设较高的初始难度。
- 如果这是一道常识性的简单题，系统会加快您的复习进度。

## 4. 您的记忆状态

在练习过程中，您可以关注以下指标：
- **到期时间 (Due Date)**：算法预测的下一次最佳复习时间。
- **复习次数 (Reps)**：您累计练习该题的次数。
- **失误次数 (Lapses)**：您在该题上答错的次数，这会显著增加该题的难度权重。

通过 FSRS 算法，我们致力于让您的每一分钟复习都产生最大的提分效益。
