# 组卷方法论：蓝图驱动的标准化模考组卷（v1 草案）

> 状态：方法定稿（2026-11-27），实现未开工。执行窗口 = 模考期（2027-01 起）。
> 定位：只定义**选题方法**（组哪些题、为什么是这些题）。试卷数据模型与 REST 契约以
> [`exam-paper-plan.md`](exam-paper-plan.md) 为准（已冻结），本文不改动任何已冻结契约。
> 复用原则：组卷结果仍落 `exam_papers`（`source='auto'` + `rules_json` 快照）；判分、
> 错题本、掌握度、历史全部沿用现有闭环，不新增学习数据路径。

---

## 0. 一条总原则

**蓝图来自真题，不来自掌握度。**
掌握度决定复习顺序（先刷弱章），不决定卷面结构——模考卷的价值在于"像真考试"，
它的每个格子（题型 × 考点 × 分值）都应锚定真题结构。把这两件事分开，是组卷
科学化的第一刀；现有 `weights: {wrong, weak, fresh}` 模式（exam-paper-plan §3）
是**针对性练习卷**，继续保留，但它不是模考卷。

## 1. 蓝图（双向细目表）——一次定稿，所有模考卷共用

产出物：`docs/test-blueprint-2027.md`（数据表，非代码）。定义一张配额矩阵：

| 维度               | 取值                              | 数据来源                               | 状态        |
| ------------------ | --------------------------------- | -------------------------------------- | ----------- |
| 题型 × 数量 × 分值 | 福建教综真题的题型构成与总时长    | **近年真题逐卷统计**（一次性人工任务） | ⬜ 待校准   |
| 考点配额           | 各大类在真题中的实际出分占比      | 同上                                   | ⬜ 待校准   |
| 难度配比           | 每格子内 低:中:高 ≈ 2:6:2（可调） | 约定默认值                             | ✅ 默认已定 |

现有语料（1,834 题，`data/jiaozong_1680/output/questions.jsonl` 实测）的分布
**只能作先验参考，不能当蓝图**——它是备考资料构成，不是考卷构成：

```
single_choice 1018 (55.5%)   multi_choice 355 (19.4%)   judgment 322 (17.6%)
主观题 139 (7.6%，一律排除出自动组卷)
考点大类根标签：教学/学生与教师/教育与教育学/课程/德育/教育的基本规律/
教育目的/学校与班级管理/教育制度/教育研究方法/教育法律法规 …（与讲义章节同构）
```

## 2. 分层抽样（机械执行层）

组卷 = 对蓝图矩阵逐格子抽样，格子内再按难度配比。实现为 `rules_json` 的**扩展模式**
（新增字段，不动现有字段语义）：

```json
{ "mode": "blueprint", "blueprintId": "fj-2027-v1", "seed": "..." }
```

- 与现有 `{wrong, weak, fresh}` 权重模式并存：权重模式=练习卷，蓝图模式=模考卷。
- 同一 `blueprintId` + 不同 `seed` → **平行卷**（同结构、不同题）；分数才可纵向比较。
- 格子候选不足时的降级顺序：同格子放宽难度配比 → 相邻考点并入 → 最后才按现有
  语义返回 400（`{requested, available, shortfall}`），不得静默缩水。

## 3. 数据筛题（同格子内的排序依据）

1. **经验难度**：题的线上正确率（`practice_logs` 聚合）。作答数 n<5 的题难度未知，
   按 来源+题型+章节 分层兜底；语料作答量上来后自动切经验值。
2. **坏题过滤（降权/剔除）**：多选题正确答案落选率异常（<30% 或最高票是错误选项）
   ≈ 争议题信号；同一题在两次作答中判分不一致（judge 回归）直接剔除并报警。
3. **知识点纯度**：tags 命中单一知识点的题优先；跨多大类的杂题不进专项/章节卷。

## 4. 曝光控制（防"测的是记忆不是掌握"）

- 近 **14 天**做过的题不进新模考卷（`excludeRecentDays` 默认值从 7 提到 14，仅蓝图模式）。
- 错题复现例外：错题要进模考卷，须距上次作答 **≥21 天**，或该题存在变体问法。
- 专项刷题（按 tag 的会话练习）**不受此限制**——专项追求全量覆盖，重复是允许的。

## 5. 组卷卡（可复核性）

蓝图模式组卷时，把**蓝图覆盖率 + 每题入选原因**（格子、候选名次、经验难度）写入
`rules_json` 快照的 `audit` 字段（纯记录，不参与判分）。任何一张卷子都能回答
"为什么是这 40 题"。

## 6. 执行排期（对齐备考期纪律）

| 时间         | 动作                                              | 量               |
| ------------ | ------------------------------------------------- | ---------------- |
| 2026-12 上旬 | 真题题型/考分统计 → `test-blueprint-2027.md` 定稿 | 一次性，人工为主 |
| 2026-12 下旬 | 选题脚本（`mode=blueprint` 服务端实现 + 组卷卡）  | 一个中等 PR      |
| 2027-01 起   | 模考期：每 1–2 周一张平行卷，追踪曲线             | 例行             |

**现在不做**：日常练习不组卷（专项按章推进，见练习流程）；组卷只属于模考期。

## 7. 明确不做

- **自适应（CAT）**：单用户作答量不足以支撑题目标定与能力估计，投入产出不成立。
- 主观题组卷（essay/short_answer 判分不走自动闭环，见 exam-paper-plan §3.4）。
- 跨用户组卷/共享卷——试卷归属用户（exam-paper-plan §1 约定不变）。
