# 组卷方法论：蓝图驱动的标准化模考组卷（v1 草案）

> 状态：方法定稿（2026-11-27），实现未开工。执行窗口 = 模考期（2027-01 起）。
> 定位：只定义**选题方法**（组哪些题、为什么是这些题）。试卷数据模型与 REST 契约以
> [`exam-paper-plan.md`](exam-paper-plan.md) 为准（已冻结），本文不改动任何已冻结契约。
> 复用原则：组卷结果仍落 `exam_papers`（`source='auto'` + `rules_json` 快照）；判分、
> 错题本、掌握度、历史全部沿用现有闭环，不新增学习数据路径。

---

## 0. 一条总原则

**蓝图来自真题，不来自掌握度。**
掌握度决定复习顺序（先刷弱章），不决定卷面结构——模考卷的价值在于"像真考试"，
它的每个格子（题型 × 考点 × 分值）都应锚定真题结构。把这两件事分开，是组卷
科学化的第一刀；现有 `weights: {wrong, weak, fresh}` 模式（exam-paper-plan §3）
是**针对性练习卷**，继续保留，但它不是模考卷。

## 2. 分层抽样（机械执行层）

组卷 = 对蓝图矩阵逐格子抽样，格子内再按难度配比。实现为 `rules_json` 的**扩展模式**
（新增字段，不动现有字段语义）：

```json
{ "mode": "blueprint", "blueprintId": "fj-2027-v1", "seed": "..." }
```

- 与现有 `{wrong, weak, fresh}` 权重模式并存：权重模式=练习卷，蓝图模式=模考卷。
- 同一 `blueprintId` + 不同 `seed` → **平行卷**（同结构、不同题）；分数才可纵向比较。
- 格子候选不足时的降级顺序：同格子放宽难度配比 → 相邻考点并入 → 最后才按现有
  语义返回 400（`{requested, available, shortfall}`），不得静默缩水。

## 3. 数据筛题（同格子内的排序依据）

1. **经验难度**：题的线上正确率（`practice_logs` 聚合）。作答数 n<5 的题难度未知，
   按 来源+题型+章节 分层兜底；语料作答量上来后自动切经验值。
2. **坏题过滤（降权/剔除）**：多选题正确答案落选率异常（<30% 或最高票是错误选项）
   ≈ 争议题信号；同一题在两次作答中判分不一致（judge 回归）直接剔除并报警。
3. **知识点纯度**：tags 命中单一知识点的题优先；跨多大类的杂题不进专项/章节卷。

## 4. 曝光控制（防"测的是记忆不是掌握"）

- 近 **14 天**做过的题不进新模考卷（`excludeRecentDays` 默认值从 7 提到 14，仅蓝图模式）。
- 错题复现例外：错题要进模考卷，须距上次作答 **≥21 天**，或该题存在变体问法。
- 专项刷题（按 tag 的会话练习）**不受此限制**——专项追求全量覆盖，重复是允许的。

## 5. 组卷卡（可复核性）

蓝图模式组卷时，把**蓝图覆盖率 + 每题入选原因**（格子、候选名次、经验难度）写入
`rules_json` 快照的 `audit` 字段（纯记录，不参与判分）。任何一张卷子都能回答
"为什么是这 40 题"。

## 7. 明确不做

- **自适应（CAT）**：单用户作答量不足以支撑题目标定与能力估计，投入产出不成立。
- 主观题组卷（essay/short_answer 判分不走自动闭环，见 exam-paper-plan §3.4）。
- 跨用户组卷/共享卷——试卷归属用户（exam-paper-plan §1 约定不变）。

## 8. 契约缺口清单（评审 19 线程归并，实现 PR 必须逐项落掉）

以下均为**实现项，不是当前行为**：现有 `POST /papers/generate` 只有权重模式，
蓝图模式（含下表全部字段与校验）随 12 月的实现 PR 一起进入契约与测试。

| # | 缺口 | 决议 |
|---|---|---|
| 1 | 蓝图模式入口未定义 | `POST /papers/generate` schema 扩展 `mode:"blueprint", blueprintId, seed`；缺省=权重模式向后兼容；`mode=blueprint` 但蓝图未注册时 422，不得静默落回权重卷 |
| 2 | 重试会产生重复试卷 | 幂等键 `(user_id, blueprintId, seed)`；重复请求返回既有卷（同 id），不新建；**同键但其余参数不同**（如 `excludeRecentDays` 变了）→ 409 冲突提示，不产生第二张 |
| 3 | 平行卷"不同题"无机制保证 | 硬约束：**同一 `user_id` 下**同 `blueprintId` 不同 `seed` 的卷题集两两零交集（试卷按用户归属，跨用户互不影响）；任一格候选不足以同时满足该用户已生成的所有卷 → 400 + shortfall，不静默重叠 |
| 4 | 降级"相邻考点并入"破坏等效性 | 请求新增 `strictBlueprint?: boolean`（默认 false）：true 时任一格需降级则直接 400；false 时触发降级的卷在 `rules_json.audit` 记 `equivalent:false`，分数不入纵向趋势曲线 |
| 5 | 难度配比无分界值 | 观测正确率 **高：<40%；中：40%–70%（两端闭合）；低：>70%**——半开约定保证每题只落一档；n<5 的题不入难度配额（仅同格无其他候选时回填，组卷卡记原因） |
| 6 | skipped 作答拉低观测正确率 | 难度统计排除 `practice_logs.status='skipped'` |
| 7 | 字母"均分"对 5/7 题不可整除 | 容差 ±1（如 7 题段 2/2/2/1）；多选配平同样按 ±1 |
| 8 | 坏题过滤信号方向写反 | 争议题触发条件 = **最高票选项不是正确答案**（most_wrong 选择率 > 正确项选择率），与正确率高低无关；判分回归检测需判分版本化（判分器版本入日志），"同题同人同答案 is_correct 变化"才可作证据——判分版本化为独立前置项 |
| 9 | 每题 1 分与真实分值不符 | exam 契约现口径（每题 1 分、0–1）是实现中间态；蓝图卷按真题分值段加权（单选/多选/判断/填空各段分值入蓝图），`exam_score` 语义扩展随实现 PR 三端同步 |
| 10 | 辨析/案例（51–58 题）候选来源 | 自动组卷只覆盖客观 50 题；主观段 v1 用真题原题（语料含参考答案），生成卷标"主观段=真题"；纯生成卷暂不含主观段 |
| 11 | 考点格子 vs 题目标签粒度不匹配 | 蓝图格子粒度=章级路径（与 1680 入库标签同粒度），不下探到单一知识点；"纯度"定义=标签命中单一章路径 |
| 12 | 语料不在本仓，数字不可复核 | 语料在两仓外路径（`fj-teacher-exam-physics/fenbi-corpus`、`data/jiaozong_1680/output`）；统计脚本在 fj 仓可复跑，本表引用处已标生成管线 |
| 13 | `excludeRecentDays` 可传 0 | 蓝图模式服务端强制 ≥14（权重模式保持可配 0–365） |
