# 用户交互流程图 (User Flows)

本文档详细描述了“AI 教招客观题智能提升系统”的核心功能交互逻辑。

## 1. 练习模式流程 (The Practice Loop)

这是系统的核心功能，用户在此进行答题并触发实时评估。

### 流程步骤
1.  **入口**：点击首页或导航栏的“开始练习”。
2.  **初始化**：
    *   系统调用 `getPracticeSessionAction`。
    *   应用 40/40/20 选题算法生成题目队列（新题/错题/复习题）。
    *   **UI**：显示加载动画。
3.  **答题环节**：
    *   **展示**：显示题干、选项（支持单选/多选）、认知维度标签。
    *   **交互**：用户点击选项或使用键盘 (1-4) 选择。
    *   **提交**：
        *   单选：点击选项即自动提交。
        *   多选：选择多个选项后，点击“确认提交”按钮。
4.  **即时反馈**：
    *   **正确**：显示绿色高亮，进入下一题（自动）。
    *   **错误**：
        *   显示红色高亮。
        *   **触发复盘**：该题被加入 `reviewQueue`（待复盘队列）。
        *   **UI**：顶部进度条下方出现黄色警告条：“您有 N 个知识点待复盘”。
5.  **结束判定**：
    *   当所有题目完成，或题目达到复盘触发阈值（默认为第 25 题或结束时）时，进入**智能复盘模式**。
6.  **中断与退出**：
    *   **触发**：用户点击页面顶部的“退出”或“返回”按钮。
    *   **拦截**：系统弹出 `ExitConfirmModal` 警告：“当前进度未保存，确定要离开吗？”。
    *   **选择**：
        *   **确认离开**：丢失当前未结算的进度，返回首页。
        *   **继续练习**：关闭弹窗，停留在当前题目。

## 2. 智能复盘流程 (The AI Review Loop)

当用户积累了错题后，系统强制进入此模式，通过 AI 辅助修补知识漏洞。这是一个线性的三阶段状态机。

### 阶段一：解析研读 (Study)
*   **触发**：进入复盘模式的第一步。
*   **展示**：
    *   **原题回顾**：高亮展示题干。
    *   **选项对比**：AI 分析用户错选项与正确项的区别。
    *   **深度解析**：RAG 检索到的教材知识点。
*   **交互**：用户阅读后点击：
    *   按钮 A：“我已掌握，开始测试” -> 进入阶段二 (Quiz)。
    *   按钮 B：“没看懂，再试一次” -> 保持当前状态或重新生成解析。

### 阶段二：纠偏找茬 (Quiz)
*   **逻辑**：AI 基于原题生成一道**变式题**（通常是逻辑陷阱题）。
*   **展示**：
    *   **AI 分析**：简短提示考点。
    *   **变式题**：一道新的单选题。
*   **交互**：用户作答。
    *   **正确** -> 进入阶段三 (Regression)。
    *   **错误** -> 提示错误，需重新研读解析（可能回退或停留在当前并扣分）。

### 阶段三：回归挑战 (Regression)
*   **逻辑**：终极测试，连续 3 道变式题（逻辑逆向、补集测试、边界压力）。
*   **展示**：依次展示 3 道高难度变式题。
*   **交互**：用户逐一作答。
    *   **全部正确** -> 🎉 复盘通过！该知识点掌握度大幅提升。
    *   **任一错误** -> ❌ 复盘失败。
*   **熔断机制**：如果用户在复盘中连续失败 3 次：
    *   系统提示“复盘熔断”。
    *   该题被移入“长期观察区”。
    *   建议用户课后查阅教材，不再在此次会话中纠缠。

## 3. 仪表盘与数据管理 (Dashboard & Data)

### 仪表盘 (Dashboard)
*   **知识图谱**：
    *   展示所有知识点（Tag）的力导向图。
    *   **颜色编码**：
        *   🟢 绿色：牢固 (>85分)
        *   🟡 黄色：一般 (60-85分)
        *   🔴 红色：薄弱 (<60分)
    *   **交互**：拖拽节点可重新布局（D3.js）。
*   **数据管理**：
    *   **导出**：点击“导出进度备份”，下载 JSON 文件。
    *   **导入**：点击“导入”，选择 JSON 文件覆盖当前数据。

### 设置 (Settings)
*   **AI 严厉度**：调整复盘触发的频率。
*   **数据重置**：一键清空所有练习记录和掌握度（慎用）。
*   **界面外观**：
    *   切换“护眼模式” (暖色温) 或 “黑暗模式”。
    *   设置偏好自动保存至 LocalStorage。

---

## 4. 历史回顾 (History Traceback)

### 历史列表 (/history)
*   **展示**：按时间倒序排列的所有练习会话。
*   **信息**：日期、总题数、正确率、复盘数量。
*   **交互**：点击任意条目进入详情页。

### 会话详情 (/history/[id])
*   **概要**：本次练习的宏观表现（卓越/加油/攻克）。
*   **答题流溯源**：
    *   完整还原当时的每一道题。
    *   **错题展开**：如果该题触发了复盘，可以展开查看当时 AI 生成的**纠偏题**和**回归挑战题**。
    *   这是用户“复习错题”的重要入口。

---

## 5. 后台管理 (Admin)

*   **入口**：访问 `/admin`。
*   **鉴权**：
    *   显示全屏密码输入框。
    *   输入正确口令 (环境变量配置) 后解锁，Session 有效期内免登。
*   **功能**：
    *   **题库导入**：
        *   粘贴 JSON 格式的题目数据。
        *   点击“导入”，系统进行去重和入库。
    *   **题目管理**：
        *   查看当前题库总数。
        *   分页浏览题目列表。
        *   删除特定题目。

---

## 6. 异常处理流程

*   **API 故障**：若 AI 服务不可用，系统自动降级为“本地 SQLite 相似题检索”模式，确保复盘流程不中断。
*   **页面崩溃**：全局 `ErrorBoundary` 捕获错误，显示友好的“糟糕，出错了”页面，并提供“返回首页”按钮。

---

## 7. AI 助教对话流程 (AI Tutor Chat)

### 7.1 功能入口
*   **侧边导航栏**：点击 "AI 助手" 或者 "Chat" 图标。
*   **快捷操作**：未来规划支持快捷键 (e.g., `Cmd+K`) 唤起悬浮对话框。

### 7.2 核心交互循环
1.  **用户提问**：
    *   在底部输入框输入教招相关问题。
    *   支持换行 (Shift+Enter) 和发送 (Enter)。
2.  **AI 思考与响应**：
    *   **思考链展示**：如果模型支持，优先展示即时思考过程 (Thinking Process)，增加透明度。
    *   **流式输出**：答案逐字显示，降低用户等待焦虑。
    *   **富文本渲染**：自动识别 Markdown，代码块高亮，表格渲染。
3.  **多轮对话**：
    *   保持会话上下文，用户可以针对上一条回答继续追问。
    *   **清除历史**：提供 "新对话" 或 "清除上下文" 按钮以重置状态。

### 7.3 异常处理
*   **生成失败**：网络中断或 API 错误时，Toast 提示错误信息，输入框保留用户原输入以便重试。
*   **敏感内容拦截**：若触发安全过滤器，显示标准拦截提示。
